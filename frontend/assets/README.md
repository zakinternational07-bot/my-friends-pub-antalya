# Медиа-файлы

Сейчас здесь плейсхолдеры (CSS-паттерны вместо фото). Когда появится
реальный контент, замени на:

- `images/hero-bg.jpg` — полноэкранное фото интерьера паба для главной
  страницы. Уже подключено (см. `frontend/html/index.html`, инлайн
  `background-image` на `div.hero`). Чтобы заменить — просто перезаписать
  этот файл другим фото того же имени, либо поменять путь в `index.html`.
- `images/menu/<N>.jpg`, `images/menu-en/<N>.jpg`, `images/menu-tr/<N>.jpg` —
  страницы готового дизайнерского меню на каждом языке. Показываются на
  `menu-ru.html` / `menu-en.html` / `menu-tr.html` через один и тот же
  постраничный просмотрщик со стрелками (`frontend/js/menu-gallery.js`,
  переиспользуется для всех трёх — список страниц и путь к папке заданы
  атрибутами `data-base`/`data-pages` на `<div id="menu-gallery">` в
  каждом HTML-файле). Чтобы добавить/убрать/переставить страницы — положи
  файл `<N>.jpg` в нужную папку и поправь `data-pages`.
  В русской версии файлы пронумерованы 1–4, 6–17 (в исходной папке не
  было страницы 5 — уточни у дизайнера, не потерялась ли она; английская
  и турецкая версии полные, 1–16).

  **Важно:** пока меню на всех трёх языках — картинки, раздел «Меню» в
  админ-панели (категории/пункты меню) ни на что не влияет — он писал в
  БД, из которой раньше собирался текстовый вариант меню. Если захочешь
  вернуть текстовое меню (например, для языка, где ещё нет готового
  дизайна) — на нужной `menu-*.html` замени блок `#menu-gallery` на
  `<div id="menu-root">` и подключи `frontend/js/menu.js` вместо
  `menu-gallery.js` (рендерит из тех же данных, что видны в админке).
- `images/events/<slug>.jpg` — постеры мероприятий. Путь указывается в
  админке при создании/редактировании мероприятия (поле «Путь к постеру»)
  и подставляется в `.event-card-photo` / `.event-detail-poster`.
- `video/<slug>.mp4` — записи с прошлых похожих мероприятий, путь
  указывается в поле «Ссылка на видео» в админке.
- `fonts/` — если нужен именно тот же шрифт, что на myfriendspub.ru,
  а не Oswald из Google Fonts (сейчас подключён через `<link>` в `<head>`
  каждой страницы), положи файлы сюда и пропиши `@font-face` в
  `frontend/css/variables.css`.
